# 💱 Currency Converter

A clean, modern, and responsive Currency Converter web application that allows users to convert amounts between different currencies instantly using live exchange rates.

## 🌟 Features

- **Currency Selection:** Choose from multiple currencies, including USD, EUR, GBP, PKR, INR, AED, SAR, CAD, and AUD.
- **Amount Input:** Enter the amount you want to convert.
- **Instant Conversion:** Automatically calculate the converted amount when the input or selected currencies change.
- **Live Exchange Rates:** Fetch the latest available exchange rates using the Frankfurter API.
- **Swap Currencies:** Quickly switch the source and target currencies with one click.
- **Exchange Rate Display:** View the current exchange rate between the selected currencies.
- **Responsive Design:** Works smoothly on desktop, tablet, and mobile devices.
- **Error Handling:** Display helpful messages when an API request fails.
- **Reset Functionality:** Clear the input and reset the converter.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Currency conversion, DOM manipulation, and API integration.
- **Frankfurter API** – Exchange rate data.

## 🎯 Project Objective

The objective of this project is to practice HTML, CSS, and JavaScript by building an interactive web application. It demonstrates DOM manipulation, event handling, API integration, asynchronous JavaScript, and responsive web design.
